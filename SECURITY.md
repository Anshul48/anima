# Security policy

ANIMA components run locally; there is no hosted service in this repository.

## Reporting a vulnerability

Report privately to the repository owner via a GitHub private vulnerability
report. Include the component, version, reproduction steps, and impact.

## Scope notes

- `components/stc/.env.example` is a placeholder template, never credentials.
- Test fixtures under `components/*/` are synthetic. If you find a real key,
  token, or private corpus in the tree, report it as above and do not quote
  it in a public issue.
