# Changelog

## 0.1.0 (2026-10-14)

First public release of the ANIMA mono-repo:

- Five independently installable components: `anima-substrate`, `sst-engine`,
  `stc`, `entorhinal`, `reflex`, plus the `anima` namespace alias package.
- Root and per-component Apache-2.0 licensing (`sst`, `entorhinal`, `reflex`
  licensed at publication; `substrate` and `stc` already carried Apache-2.0).
- Curated `docs/anima/` background (proposals, syntheses, reading room,
  module catalogue, freeze pins); operational records excluded.
- Import-map smoke tests (`tests/`), per-component suites, CI on push/PR.
