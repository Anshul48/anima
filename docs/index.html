ANIMA in 30 seconds

What: Superintelligence will not come from a bigger model alone. ANIMA externalizes intelligence into the environment: persistent project worlds, heuristic search, spec-to-code construction, advisory memory, and computer-use perception — durable scaffolds around models so cognition lives in the system, not in a single prompt. (Source: root README.md, “ANIMA in 30 seconds”.)

Who it helps: agent builders who need attributable, budgeted local execution across many models. Proof (one line): substrate replays a 7-step journey ending byte-identical; SST replays a real task-to-result UI journey plus a kept failure leg. Details on the module pages.

The dream vs. today

ILLUSTRATED direction The dream

Direction, not a claim about what exists. A dynamic substrate that rewires itself while it runs; software that evolves under search, selection under deterministic gates, inheritance through versioned genomes. (Source: root README.md, “The dream”, which states the composition it describes is a proposal today, not shipped wiring.)

REAL-REPLAY What exists today

Five independently installable research components plus a thin alias namespace. No shared server, no cross-component wiring, no hosted service. Each module page below replays or receipts what its component actually does. (Source: root README.md, “What exists today”.)

TRACE — the memory layer

ANIMA’s memory story is TRACE: a frozen 10M-token build (seam12a) organizing 10,003,381 tokens into 13,081 docs and 63,441 atoms, recall@10 0.7367 (all) / 0.4883 (leave-schema-out). Figures from root README “Proof” (2026-10-18). Live explorer: TRACE explorer.
