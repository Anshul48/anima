# Proposed GitHub About (for maintainer review; not yet applied)

**Description:** Reusable Python components for persistent state, heuristic
search, code generation, temporal context, and computer-use perception.

**Topics:** `python`, `research-tools`, `heuristic-search`,
`code-generation`, `temporal-context`, `computer-use`, `apache-2-0`

Component descriptions (source-justified): substrate (persistent project
worlds, crash-atomic local state), sst (heuristic dialectic-MCTS search),
stc (spec-to-code engineering with quality gates), entorhinal (advisory
temporal context), reflex (vision/perception for computer use). Components
are independently installable; `anima.*` modules are import aliases only,
with no shared runtime.
