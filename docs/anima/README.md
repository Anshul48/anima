# ANIMA

ANIMA is the approved umbrella and workspace name for the developing system. Its intended direction includes attributable memory, reusable computational knowledge and procedures, learning, execution, and cooperating worlds. The vision phrase is still open; “Living Holonic Cosmos” and “Fractal Holonic Cosmos” remain alternatives, not settled wording. ANIMA is not expanded as an acronym.

This home organizes context, ownership, source identities, releases, and future compositions. It is not itself a runtime, a monorepo, or evidence that the proposed worlds or adaptive mechanisms have been implemented.

## How to read this workspace

Folders classify records and ownership responsibilities. They do not assert runtime containment. A source component can expose several capabilities and serve several worlds; worlds can host other worlds; composites can become participants elsewhere. Source location, runtime placement, state custody, ownership, access, and execution location stay separately recorded.

Create a directory when it has actual content or an assigned responsibility. Keep original conversations and evidence at their source. Earlier provisional organization drafts are preserved under `context/provenance/initial-ecosystem-draft-2026-10-02/`; the legacy `ecosystem/` folder has been audited and removed.
