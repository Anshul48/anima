# World definitions

This directory is for actual domain environment definitions and composition records. A world owns its local goals, state, representations, tools, authoritative outcome interpretation, and exported obligations. Its manifest may reference components or other worlds without controlling where their source lives.

Construction and a distinct research/constraint-solving environment are proposed in the active programme; their host, state boundaries, and exact definitions remain work items. No runtime world is created by this organization pass. See `autonomous_runs/trace_ecosystem_20261002/PROGRAMME.md` and its W0–W3 and E0 work definitions.
