## How authority is labeled

Use `USER-DIRECT`, `USER-PASTED/ATTRIBUTED`, `ACCEPTED`, `PROPOSED`, `WORKING`, `REPORTED`, `INSPECTED`, `REPRODUCED`, `DEFERRED`, and `SUPERSEDED` precisely. A user message may contain prior-model prose; host role and actual authorship are separate. A reported result or inspected code is not an independently reproduced result. A proposal or folder is not an implementation. Scope all requirements, exemptions, and future obligations to their owning release, run, project, or programme.

## Update discipline

Preserve original conversations and project evidence. Add attributable deltas when a live conversation grows; record an indexed line/byte frontier and content identity where available. Never silently change source authority, deduplicate away differences of chronology or scope, turn a historical task queue into current authorization, or let a mutable source path stand for a frozen version.
