## Direct cross-vector corrections and extensions

- **A/C/B/D:** A, computationally useful knowledge; C, learned schemas and operations; B, cumulative capability discovery; D, computational/physical co-design. User wants A first and D last, swaps B/C because B nears RSI, expects many intermediate steps, and does not require rigid phases. (User L1261 and L1325.)
- **Capability over theory as deliverable:** actual useful capability is the objective; theory matters when it helps. Preserve the Sept 29 ambition for intelligence-guided accelerated evolution alongside the later staged map; do not elevate one to a current implementation mandate. (STC session `01a0edb2…` L9/L127; agent report.)
- **Learning now, stronger claims later:** STC may record experience and automate/revise workflows now. Prediction discrepancy, explicit correction and comparative performance are different feedback types. A learning insertion point is not an adaptive learner. (Programme user L466; STC owning mandate and current direction.)
- **Worlds and broader collaboration:** worlds can host worlds; boundaries, participants and responsibilities may change; environments may adapt and compose/mutate existing primitives for a specific need. The intended collective is not confined to one human and one AI; it can involve many people, AI systems, tools, computational worlds and eventually physical systems. (Main vector session L1177, L1261, L1568; direct prompt portions retained in excerpts.)
- **Multi-timescale development:** TRACE can be a world inside a broader cognitive architecture within hardware/software co-design. Coordinators attend to current tasks while roadmaps preserve the future; model attention and other resource costs. (User L1424.)
- **Autonomous initiative:** an AI may make useful associations, suggest work, learn where user contribution matters, ask clarifying questions before wasteful branches and take on routine tasks. The user marks the podcast exposition as weaker-model context and says not to inspect the Entorhinal project deeply now. Preserve the ambition without taking the embedded technical assertions as evidence. (User L1493.)
- **Prospective project participants:** a later user turn names Entorhinal and Reflex among projects that could join the wider system and gain access to TRACE/SST; another says to resume Reflex's perception work before grander ambitions. This is future-canvas context only: neither project has been inspected and catalogued here, assigned a current owner/pin, nor authorized for launch. (Sessions `01a0fd9a` L9/L17 and `01a0ee54` L9/L118; see `SOURCES.jsonl`.)
- **Illustrative domain schemas:** the user gives frontend, Blender and Unreal development as examples of domain schemas an AI could mix and match. This is an example of the ambition, not evidence that those schemas or capabilities exist. (Main vector session L1568; exact direct excerpt below.)
- **Historical “trace lite” wording:** one earlier user turn calls `trace-architecture` a different attempt at building “trace lite,” then asks for something more like TL and less like `trace-lite`. Preserve the wording as ambiguous history; current owner records keep TL, TRACE and sibling `trace-lite` separate. (Session `01a0f050` L9.)

## 8-Vector Developmental Worlds Round (2026-10-05 to 2026-10-07)

*Namespace Note: These vectors (01–08) represent the in-depth developmental worlds round and are distinct from the earlier 18-vector landscape round (V1–V18).*
