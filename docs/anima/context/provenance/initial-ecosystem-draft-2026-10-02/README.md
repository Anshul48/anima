The dated programme remains the owner of its active charter, DAG and run state. This home supplies stable navigation and the organization proposal. A later relocation should move authority deliberately and update links rather than create competing copies.

The immediate distinction is between reusable implementations, environments assembled from them, inherited procedures, and the particular executions that generate evidence. Runtime worlds may nest, overlap in function, cooperate, merge or split while source projects retain stable identities and histories.
