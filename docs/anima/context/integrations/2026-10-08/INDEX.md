## 3. Disambiguation & Alias Glossary

| Term / Alias | Formal Disambiguation |
|---|---|
| **Substrate (Broad)** | World-hosting environment, lifecycle, state custody, and dynamic boundary framework (`hosting.substrate`). |
| **Substrate (STC Package)** | Local execution support library inside `stc/` (`stc.substrate`). Not world hosting. |
| **TL (Family)** | Selected attributable source memory family: `trace-architecture/tl-candidate-batch` + `trace-architecture/tl-sys`. |
| **trace-lite** | Independent sibling implementation of source extraction; distinct from TL family. |
| **SST (Module)** | Standalone search and candidate generator (`search.sst`). |
| **SST (Search Heuristic)** | General concept of structured candidate search across any state space. |
| **18-Vector Round** | Initial October 1–3 exploratory round (Vectors V1–V18). Broad scope mapping. |
| **8-Vector Round** | October 5–7 Developmental Worlds round (Vectors 01–08). Deep developmental design. |
| **Entorhinal** | User activity tracking project located at `utilities/entorhinal` for relational tracking. |
| **Ecosystem (Legacy)** | Provisional 2026-10-02 folder, now fully deleted; original drafts preserved in `provenance/`. |
