Substrate — durable project worlds

What

Substrate pins release files, runs budgeted participant families (e.g. relcheck), and settles stranded budgets to zero. This is an alpha research artifact (0.1.1), not a production runtime. (Source: components/substrate/README.md.)

Who it is for

Agent builders who need attributable, budgeted local execution: every run is pinned to file hashes, every delegation carries an operator-supplied budget, and close/reopen is byte-verified.

Limits

Single host, toy scale, process-crash-only (no fsync; power/media loss is out of scope). No cross-host, multi-writer, or disk-loss tolerance. No learning of any kind: no policy invention, learned mappings, or autonomous discovery. Delegation amounts are operator-supplied. STC material is explicitly unqualified (full-replay semantics only). (Source: component README, “Important limitations”.)
