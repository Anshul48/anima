Like a notebook that survives a house fire: burn the house down, open the notebook, every word still there. Then merge your notebook with a teammate's.

Try it

  1. Run the verified tour — block below is an exact copy of root README “Quickstart”: 
    git clone https://github.com/Anshul48/anima.git
cd anima

# Create and activate an isolated Python 3.12 virtual environment:
python3.12 -m venv .venv
source .venv/bin/activate

# Or using uv:
# uv venv .venv --python 3.12 --seed && source .venv/bin/activate

# Install the root alias package and the stdlib-only substrate component:
pip install -e . -e components/substrate

# Execute the verified substrate journey (participant run, byte-identical close/reopen):
python examples/quickstart.py   # ends with: ANIMA quickstart OK

Scroll-typed, real command + recorded output:

$ python examples/quickstart.py
ANIMA quickstart OK

Limits

  • One computer, small scale, survives force-quit — not power cuts or disk failure.
  • It learns nothing: no invented rules, no discoveries on its own.
  • Early research build (0.1.1), not production software. Full list in the component README.
