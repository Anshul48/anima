# SST Visualizer Assets

This directory contains static assets for the State Space Tree (SST) DAG Visualizer:

- `visualizer.css`: Styling rules for the DAG sidebar, node badges, layout, and control panels.
- `visualizer.js`: Core Cytoscape initialization helpers and HTML sanitization utilities.

These assets complement the embedded interactive HTML visualizer produced by `sst.visualizer.server.render_html_visualizer`.
